# docs — fumadocs (Next.js)

Documentation site, deployed on Cloudflare.

This is a stub. Scaffold the fumadocs app files (`source.config.ts`,
`next.config.mjs`, `app/`, `content/`) by copying `ref/apps/fumadocs/*` or:

```bash
bunx create-fumadocs-app@latest
```

Then write docs under `content/docs/`. The library API lives in
`packages/core` (`@eggermarc/better-auth-usage`).
